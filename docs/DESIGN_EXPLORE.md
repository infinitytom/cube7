# 探索 · 战斗 · 进化（v2 设计）

> 目标：节奏更慢、更从容；体素不只是“能拆”，而是“探索的语言”。

## 1. 核心循环：看 → 扫 → 想 → 挖 → 建
1. **看**：平滑的自然地形（Voxel Tools Transvoxel）让地貌本身成为线索——鼓起的土丘、荧光菇、裂开的石板。
2. **扫**：回声扫描（L2 / Q / 鼠标中键，冷却 2.5 秒）。声呐波扫过地形，标出：
   - 回声晶核、种子方块、记忆碎片、宝箱（隔着地层看得见）
   - 金矿、晶簇（值得挖的地层）
   - **承重点**（支撑木架，橙色）：撞断它，上面的东西会塌——这是解谜和战斗共用的提示
3. **想**：从哪里挖进去？钻头隧道、滚球撞开、还是先烧掉木架让上面塌下来？
4. **挖**：破坏按材质有不同的手感——泥土是碗状坑和飞溅的土块，岩石按 Voronoi 裂成几大块崩飞，木头碎成长木片，玻璃是薄片。
5. **建**：拆下来的东西变成重构物质，重建桥梁、瞭望台；重构塔点亮时砸烂的地形一圈圈飞回原位（圆角方块飞回，落地后停留 0.3 秒盖住网格重建，不闪空洞）。

## 2. 关卡里的体素支线（每章自动生成，固定种子）
- **回声晶洞**：每章 5 个，埋在离地表 1.5～3.5 米的普通地层里，四周和关卡谜题保持距离。洞壁长着共鸣晶簇（撞碎会连锁崩落、掉金币）。
- **地下洞穴**：2 条从地表蜿蜒向下的天然隧道，入口一圈荧光菇，洞壁零星发光；尽头离晶洞还差一米多，被松土堵着——扫描看得见墙后的晶核，钻开就到。
- **落石陷阱**：敌人营地旁边的支撑木架托着一块圆石。撞断木架 → 木架连锁崩塌 → 圆石整块掉下来，砸扁附近的锈块兽，落地后变成地形的一部分。

## 3. 战斗：用世界打架
- 锈块兽是“生病的机器”，打法仍然是机制型（绕背、踩头、气浪掀翻）。
- 新增**环境击杀**：任何下落的碎块（坍塌的结构、崩飞的岩块、落石）速度超过 3 m/s 时会砸伤敌人；大型 Boss 会被震晕。
- 推荐的玩法：扫描找到承重点 → 引敌人过去 → 撞断木架。

## 4. 进化路线（花回声晶核，暂停菜单 →「形态进化」）
| 进化 | 形态 | 晶核 | 改变了什么 |
|---|---|---|---|
| 深层回声 | 通用 | 2 | 扫描半径 14 → 22 米 |
| 回声视界 | 通用 | 2 | 扫描标记停留 6 → 12 秒 |
| 螺旋钻头 | 钻头 | 3 | 能钻悬崖岩、锈岩、深渊岩、岩石——每章有 1～2 颗晶核埋在这些岩层里 |
| 震荡冲撞 | 滚球 | 3 | 冲撞范围更大，满蓄力能撞开岩石 |
| 共鸣气泡 | 气泡 | 2 | 气浪震碎共鸣晶簇和碎裂石板，把附近的晶核吸过来 |

金币改装（护盾、蓄力、冲角……）保留，是“数值成长”；进化是“能力成长”，决定能去哪。

## 5. 节奏
- 滚球巡航速度 7 → 6.3 m/s、加速度更柔（加速冲刺的速度不变，谜题的速度门槛不受影响）。
- 镜头跟随更从容；限时挑战多给 40% 时间。
- NOVA 在开局 45 秒后提示一次扫描（每个存档只提一次）。
