# 开发记录

（早期 README 与各版本更新说明，按时间顺序保留）


体素箱庭解谜冒险。当前版本包含区域 1「翠绿温室」的完整关卡（方块体素版），以及一个机制测试房间。
下一阶段会把体素底层迁移到 Voxel Tools 的平滑地形（雾锁王国式的破坏）。

## 运行

1. 用 Godot 4.6（官方版或 Voxel Tools 定制版都可以）打开本文件夹里的 `project.godot`。
2. 按 F5 运行。

## 代码结构

```
scripts/
  voxel/blocks.gd        方块类型表（颜色、谁能破坏、掉落）——调数值改这里
  voxel/voxel_world.gd   体素世界：分块网格、碰撞、破坏、砂块下落
  voxel/pickup.gd        金币/能源：自动飞入球体
  player/morph_ball.gd   主角：五种形态的物理参数与能力

  puzzles/               插槽、能量回路、压力板、气流、检查点、变形站、NOVA 对话触发

  ui/hud.gd              界面
  debug/autotest.gd      自动测试
```

## 关卡与测试

- 默认进入区域 1「翠绿温室」；加参数 `-- --level=test` 进入机制测试房间。
- 设计原则：主角默认不能跳（致敬平衡球），高低差靠坡道、弹跳垫和形态能力；往下钻只对松土有效，避免把自己困住。

```
godot --headless --path . -- --autotest=greenhouse   # 区域 1 整关测试，按设计路线走到终点
```

## v2.0：奥德赛风的平滑地形、回声探索、马造式编辑器

### 画面
- **平滑地形**：草、土、岩、沙、崖壁、树冠这些自然材质改由 Voxel Tools 的 **Transvoxel** 生成平滑曲面（4 层材质混合），
  底层仍然是 0.25 米的体素：破坏、坍塌、重构、编辑器都不变。用标准版 Godot 打开时自动退回 GDScript 的 Surface Nets（`scripts/voxel/smooth_mesher.gd`），画面一致。
  - 平滑地形按渲染组（16³ 体素）整块生成：`TerrainMesher`（`scripts/voxel/terrain_mesher.gd`），每组约 2 毫秒。
  - SDF = 0.5 − (0.55 × 原始填充 + 0.45 × 3×3×3 模糊)：既圆润，又不会吃掉一格厚的细节；模糊用 VoxelBuffer 的 C++ 运算完成。
  - 材质槽位：`TerrainPalette`（16 种），着色器 `shaders/voxel_terrain.gdshader` 按槽位混合颜色和“草 / 树冠 / 砂 / 打不坏”的风格。
  - 人造物（箱子、金属、木板、建筑）保留圆角方块，和平滑地形形成“软地形 + 硬积木”的对比；挨着地形的方块面会画出来，不留缝。
  - 远景浮岛、掉落的碎块也用同一套平滑网格。
- **卡通光照**（`shaders/toon_light.gdshaderinc`）：柔和的明暗交界、冷色的背光面、迎光轮廓上的暖色边缘光（地面不加）、小而柔的高光。
- 配色调暖调亮（草更黄绿、泥土更橙），去掉自然地形上的格子和铆钉；可破坏方块的边框更含蓄。
- 柔和环境光遮蔽（设置里可关）。

### 破坏与重建
- 坑口由连续噪声决定（不再是逐格随机的麻点）；岩石重击按 Voronoi 裂成几大块崩飞（`VoxelChunk.fragment`）；泥土碗状坑 + 土块；木头碎成长木片；玻璃薄片；树叶飘落。
- 碎屑按材质换形状（不规则小石块、土块、木片、薄片）。
- 断开掉落的大块用平滑网格，小碎块用凸包碰撞，会像石头一样滚。
- 下落的碎块会砸伤敌人（环境击杀）。
- 重构动画改为圆角方块；落地后在原位停留 0.3 秒盖住网格重建的几帧，不会闪出空洞；积压多时网格重建预算自动加大。
- 破坏遍历只扫球内体素、直接读数组，大坑开销降了约 15%。

### 探索（详见 `docs/DESIGN_EXPLORE.md`）
- **回声扫描**（L2 / LT / Q / 鼠标中键）：声呐波扫过地形，隔着地层标出回声晶核、种子方块、记忆碎片、宝箱、金矿、晶簇和承重点。
- **回声晶核**：每章最多 5 颗埋在地层深处的晶洞里，拾取时读出一段“星球的回声”（剧情新增的一层）。
- **形态进化**（暂停菜单）：深层回声、回声视界、螺旋钻头（能钻崖壁）、震荡冲撞（能撞开岩石）、共鸣气泡。
- 每章自动生成的支线：通往晶洞的**地下洞穴**（荧光菇指路、尽头用松土堵着）、敌人旁边的**落石陷阱**。全部避开原有谜题，六章整关测试照常通过。
- 节奏放慢：滚球巡航速度 7 → 6.3 m/s（加速冲刺不变），镜头跟随更从容，限时挑战多 40% 时间。

### 关卡编辑器（参考《马力欧创作家》）
- 顶部 **10 格快捷栏**（L1/R1、数字键 1～0、滚轮），当前物块显示大图标 + 属性说明（撞碎需要几 m/s、钻头可钻、会塌、可燃、导电……）。
- **全部物块面板**（□ / Tab）：按“自然地形 / 建筑 / 可破坏与机关 / 物件 / 敌人”分组，每个都有图标（平滑地形画成土丘、玻璃半透明、发光有光晕、角标表示能不能撞碎 / 钻 / 会不会塌）。
- **框选铺满 / 清空**（L3 或 Shift + 拖），**吸管**（R3 / Q），**撤销 / 重做**（Create/View、Ctrl+Z / Ctrl+Y，按住 R2 重做，最多 60 步），**从光标处试玩**（R2 + △ / Shift+T）。

### 测试
- `--chapter=1 --debugscript=res://scripts/debug/test_explore.gd`（探索系统）、`--editor --debugscript=res://scripts/debug/test_editor.gd`（编辑器，含新功能）。
- 测试需要 Voxel Tools 版 Godot 才会走 Transvoxel；标准版走 Surface Nets。

## v2.1：主线 = 探索 → 关键道具 → Boss；美术统一、破坏不卡

### 主线结构
- 每章都有一枚**关键道具「进化芯片」**（`scripts/explore/chapter_key.gd`）：埋在晶洞里（会有一条地下洞穴通过去），
  或压在第一座重构点附近的塌方堆里。回声扫描把它标成金色的「关键道具」。
- 拿到芯片：PIX 立刻进化出本章的新能力——回声芯片（深层回声）、震荡芯片（震荡冲撞）、螺旋芯片（螺旋钻头）、
  共鸣芯片（共鸣气泡）、视界芯片（回声视界）、星核钥匙（终章）。
- 每章 Boss 身上裹着一层**锈封印**：没有芯片打不进去，NOVA 会把目标改成“去找芯片”；带着芯片走近，封印共鸣碎掉，开打。
- 第一章新增 Boss **锈根兽**（`scripts/enemies/root_hulk.gd`）：背着岩甲，撞、钻、砸都没用。
  扫描找到场地边木架托着的落石 → 引它冲到木架下 → 撞断木架让落石砸中它 → 岩甲裂开、四脚朝天 4 秒 → 这时打它。三击打倒；
  落石用完会一格格重构回来。打倒后终点浮岛的光门才出现。

### 美术
- 去掉“塑料感”：地形、积木、模型统一换成哑光材质（粗糙度 0.85～0.92、高光 0.2），整体亮度和饱和度往下收，ACES 对比略加。
- 每种材质有自己的表面细节法线：草是细密的草叶、岩石是粗颗粒和裂面、泥土是土粒、砂是风纹、树冠是一簇簇叶团；
  细节的凹处同时压暗颜色，质感更“实”。草地加了细碎的深浅草点，绿色更沉。
- 外部模型（Kenney 等）首次实例化时统一换成同一套哑光卡通材质（`Kit._matte`），和体素世界不再像两套美术。

### 性能：破坏不再卡顿
- 地形网格快速路径：直接把 8 位整数 SDF 写进 VoxelBuffer（`TerrainMesher.build_vt_fast`），每组 0.9 毫秒（原 2.3），几何完全一致。
- 断开检测（会不会塌）改成延迟 + 分帧：访问戳代替字典、遇到锚点提前退出、每帧 5 毫秒预算。
- 连续撞击的破坏合批处理，信号在批末一次发出。实测连撞岩壁 p95 9 毫秒；24 个大坑的压力测试平均 57 → 39 毫秒。

### 手感
- **钻头原地按住往下钻在哪里都有效**：钻出一个漏斗形的坑（坑壁有坡度，能自己滚上来），不会再在原地空转。
