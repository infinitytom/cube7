# 开发记录

（早期 README 与各版本更新说明，按时间顺序保留）


体素箱庭解谜冒险。当前版本包含区域 1「翠绿温室」的完整关卡（方块体素版），以及一个机制测试房间。
下一阶段会把体素底层迁移到 Voxel Tools 的平滑地形（雾锁王国式的破坏）。

## 运行

1. 用 Godot 4.6（官方版或 Voxel Tools 定制版都可以）打开本文件夹里的 `project.godot`。
2. 按 F5 运行。

## 形态

| 形态 | 重量 | 能力 |
| --- | --- | --- |
| 滚球 | 1.0 | 冲刺（可撞碎玻璃） |
| 钻头 | 2.5 | 按住向前钻；静止时向下钻 |
| 立方 | 3.0 | 空中重压；够重能压动压力板 |
| 磁铁 | 1.4 | 按住吸附金属墙，推向墙面往上爬 |

## 代码结构

```
scripts/
  voxel/blocks.gd        方块类型表（颜色、谁能破坏、掉落）——调数值改这里
  voxel/voxel_world.gd   体素世界：分块网格、碰撞、破坏、砂块下落
  voxel/pickup.gd        金币/能源：自动飞入球体
  player/morph_ball.gd   主角：五种形态的物理参数与能力
  player/camera_rig.gd   第三人称镜头
  puzzles/               插槽、能量回路、压力板、气流、检查点、变形站、NOVA 对话触发
  levels/test_room.gd    测试关卡（代码搭建）
  ui/hud.gd              界面
  debug/autotest.gd      自动测试
```

## 关卡与测试

- 默认进入区域 1「翠绿温室」；加参数 `-- --level=test` 进入机制测试房间。
- 设计原则：主角默认不能跳（致敬平衡球），高低差靠坡道、弹跳垫和形态能力；往下钻只对松土有效，避免把自己困住。

```
godot --headless --path . -- --autotest              # 机制测试房间，22 项
godot --headless --path . -- --autotest=greenhouse   # 区域 1 整关测试，按设计路线走到终点
```

## 音频

`audio/` 下的音乐和音效由 `tools/synth_audio.py` 程序合成（numpy + ffmpeg）。
区域音乐分三层（底层 / 旋律 / 明亮）同步循环，由 `scripts/game/music.gd` 按游戏状态自动混音。

## 画风与素材（v0.6）
- 方向：**可爱外表 + 科幻内核**。Kenney 新版粉彩配色——薄荷绿草地、珊瑚色泥土、淡紫科技件、阳光黄点缀。
- 现成素材放在 `assets/`，统一从 `scripts/art/kit.gd`（`Kit.model()` / `Kit.mesh()`）取用；授权见 `assets/CREDITS.md`（Kenney CC0 + OFL 字体）。
- 树、花、蘑菇、石头是 `Prop`（`scripts/props/prop.gd`）：高速滚撞 / 冲撞 / 钻 / 下砸会“啵”地弹飞并掉金币。
- 界面字体：Fredoka（英文数字）+ 站酷快乐体（中文）；按键提示使用 Kenney Input Prompts 真实按键图标，并直接嵌在 NOVA 的台词里。
- 素材预览：`godot --path . --rendering-driver opengl3 -s res://tools/gallery.gd -- res://assets/kenney/platformer /tmp/out.png`

## v0.8：大气远景 + 战斗扩充

### 世界
- **天空**：`shaders/sky.gdshader`——分层渐变、太阳光晕、地平线积云带、高空卷云、带光环的巨型行星和卫星。每章一套配色（`scripts/game/atmosphere.gd`）：第一章晴朗上午，第二章工坊黄昏。
- **远景**（`scripts/world/`）：和玩法世界同一套方块与着色器的“大体素”远景，在后台线程生成（结果会缓存）。
  - 第一章：北面带山峰和瀑布的「云脊」母岛、西边樱花岛、南边小岛群、从云海拔起的石柱、东北方远处的**方舟星核塔**和其余四座重构塔。
  - 第二章：冒烟的工厂浮岛、慢慢转动的巨型齿轮、锈红色钢桁架、西边远处第一章的浮岛（第一座塔的光柱）。
  - 玩法浮岛底下自动生成向下收拢的巨大岩体（石笋、水晶、垂下的草根），岛边有瀑布流进云海。
- **第一章新区域**：西北角的粉色古树（螺旋树枝平台 → 树屋宝箱 + 记忆碎片 + 眺望星核塔）、南边的锈蚀营地（清光敌人打开笼子救出第 4 只噗噗）、E 高台上的环形天线遗迹和断掉的单轨、18 米高的重构塔（点亮后光柱冲天）、岛边的岩石。
- **第二章新区域**：大烟囱（气泡顺着热气流飘到顶上：宝箱 + 第 4 只噗噗）、储料场的炮台、厂房墙上咬合转动的大齿轮、Boss 场地和更高的重构塔。

### 战斗
| 新攻击 | 操作 | 说明 |
| --- | --- | --- |
| 踩踏 | 跳起来落到敌人头上 | 所有形态都行，踩完弹起来（按住跳弹得更高） |
| 蓄力冲刺 | 滚球静止时按住能力键，松开 | 蓄满后冲刺速度 15 m/s，能正面撞碎锈块兽的盾牌 |
| 泡泡弹 | 气泡形态按住能力键，松开 | 把敌人困在泡泡里飘起来，破掉后摔翻；能包住锈弹 |
| 打回炮弹 | 气泡形态气浪 | 把飞来的锈弹原路打回去 |
| 投掷 | 抓起物件扔向敌人 | 砸翻 / 砸晕 |

| 新敌人 | 行为 | 解法 |
| --- | --- | --- |
| 锈蜂 | 盘旋，锁定后俯冲（地上有红圈） | 俯冲扎地后撞它；跳起来撞/踩；气浪、泡泡弹打落 |
| 刺壳虫 | 背上尖刺，定时收起 | 收刺时冲撞；钻头无视尖刺；下砸/气浪掀翻 |
| 锈炮台 | 抛物线锈弹 | 躲开冲过去撞；气浪把炮弹打回去 |
| **熔炉守卫**（第二章 Boss） | 冲锋、震地冲击波、召唤锈蜂、连发锈弹 | 引它撞石柱晕眩，撞背后的熔炉核心三下；打回的锈弹能直接炸晕它 |

Boss 战有专门的配乐（`tools/synth_boss.py` 生成，三层随阶段加强）。

## v0.9–v1.0：破坏与重构、完整六章、改装、关卡编辑器

- **破坏感**：草、土、苔、木、树冲刺就碎；锈铁、铺路石要蓄力冲刺；岩石、崖壁、合金是地基。下砸砸出大坑，断开的部分整块塌落。
- **重构**：拆下的每一格都变成「重构物质」。重构点（发光蓝图）可以把瞭望台、断桥、断坡一块块建回来。点亮重构塔时会有重构波，把砸烂的地形飞回原位。
- **章节**：一 温室群岛、二 齿轮工坊、三 晶簇深渊、四 云顶之城、五 锈海（潮汐、锈海吞噬者、灯塔重建）、终章 星核（锈蚀之心、结局与制作人员表）。
- **改装 PIX**（暂停菜单）：用金币买永久升级，跨章节保留。
- **手柄**：✕/A 确认、○/B 返回；设置界面整行高亮，左右调数值；手柄震动可调强度。
- **关卡编辑器**（标题画面）：摆方块和物件（出生点、终点、检查点、金币、宝箱、种子、弹跳垫、上升气流、6 种敌人），一键试玩；5 个本地存档位；导出成 .cube7 文件分享（见 v1.1）。
- **测试**：`--autotest`、`--autotest=greenhouse|gearworks|abyss|city|rust|core`；编辑器用 `--editor --debugscript=res://scripts/debug/test_editor.gd`；手柄菜单用 `--debugscript=res://scripts/debug/test_ui_pad.gd`。
