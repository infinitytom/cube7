# 《方舟星球 VOXEL ARK》世界观与剧情

> 为了救下这颗星球，她把它拆成了方块。

## 一句话
一颗被“拆成方块”保存下来的星球，一只不会说话的维护小球 PIX，要把它一块一块地重新拼回来。

## 为什么叫“方舟星球”
“方舟”的“方”就是方块。整颗星球被方舟引擎转换成了体素态——陆地、森林、城市和居民，全部变成可以拆开、也可以重新拼起来的方块，漂浮在云海护盾之上，像一艘由方块组成的方舟，躲过了那场灾难。
体素不是画风，而是这个世界的物理规则：所以 PIX 能撞碎、钻穿、拆掉世界里的大部分东西。

## 背景
- **星球：** 伊甸-7。人类的第七颗殖民星，气候温和，满是森林与湖泊。人类殖民者和原住民“噗噗”在这里一起生活。噗噗是一种圆滚滚、爱唱歌的小生物。
- **灾难：** 恒星赫利俄斯每隔几百年会爆发一次“日冕潮”。星历 3124 年的那次日冕潮强度远超预测，足以剥掉大气、烧穿地壳。撤离已经来不及了。
- **方舟引擎：** 首席科学家艾拉·林博士研究了十年的装置。它能把物质转换成极其稳定的“体素态”，保存所有信息，日后再原样重构。
  - 在日冕潮抵达前的最后一小时，艾拉启动了引擎。整颗星球被拆成方块，托上高空的云海护盾，等待风暴过去。
  - 12,000 名居民（人类和噗噗）被封存进“种子方块”，散落在各个浮岛上。
- **计划：** 三年后风暴平息，五座“重构塔”同步点亮，方舟引擎在星核里重新拼好整颗星球。

## 现在（游戏开始）
- 三年期满，星球却没有被重构：五座重构塔全部熄灭，与轨道站的通讯中断。
- **锈蚀：** 体素态数据在漫长的等待中开始“生锈”。锈蚀会腐坏方块，也把原本负责维护的小机器变成了狂躁的“锈块兽”。
- **PIX：** 轨道站“摇篮号”上的一台维护探测球，按预设程序在三年期满时自动发射，结果一头栽进了翠绿温室的浮岛。它不会说话，只会“哔啵”；但它能变形，能拆方块，也能把方块重新接通。
- **NOVA：** 引导 PIX 的站点 AI，冷静、嘴硬、偶尔毒舌，对艾拉的事情总是欲言又止。

## 星球的回声（v2 新增）
方舟引擎拆星球的时候，存下的不只是方块——每一块地层里都封着它“生前”的一点记忆：喷淋头早上六点打开的声音、工坊下班时走调的汽笛、灯塔看守人每晚对海说的那句“晚安”。
这些记忆在体素态里慢慢沉到了地层深处，结成发光的**回声晶核**。

- PIX 的探测器能发出**回声扫描**：声呐扫过的地方，埋在地下的晶核、种子方块、矿脉、承重的木架都会隔着地形亮起来。
- 游戏的节奏因此放慢了：停下来、扫一下、想想从哪挖进去——这颗星球是被“挖开来认识”的。
- 晶核是**形态进化**的材料。进化不是数值变大，而是“能去的地方变多”：钻得穿崖壁、听得见更深的回声、撞得开岩石。
- 每一章 5 颗晶核，读出来是 5 段小小的回声；越往后的章节，回声越接近日冕潮来临的那一天。
  终章的最后一段回声是 NOVA 第一次开口说的话——“……好吧，我来看着。”这是艾拉就是 NOVA 的又一条暗线。

## 玩法与剧情的对应
| 游戏元素 | 在故事里是什么 |
|---|---|
| 可以破坏的方块 | 体素态的星球本身 |
| 金币 | 散落的“体素能量”，重构时的原料 |
| 重构塔（每个区域一座） | 方舟引擎的五个节点，点亮后才能重构 |
| 种子方块（每个区域 3 个） | 被封存的居民，打开后噗噗会跳出来道谢 |
| 记忆碎片（每个区域 3 块） | 艾拉的研究日志，拼出真相 |
| 锈块兽 | 被锈蚀侵蚀的维护机器 |
| PIX 的三种形态 | 维护球的三种工作模式：滚球巡检、钻头挖掘、气泡勘测 |
| 回声扫描 | 探测器的声呐：听地层里还留着什么 |
| 回声晶核（每章 5 颗） | 沉在地层深处的星球记忆；进化 PIX 的材料 |
| 形态进化 | 维护球被星球的记忆“教会”了新的工作方式 |
| 地下洞穴、荧光菇 | 记忆渗出地表的通道：顺着光往下走，就能找到回声 |

## 章节
0. **序章 · 坠落**：日冕潮、方舟引擎启动、三年后 PIX 坠落。
1. **翠绿温室群岛**：原来的生态研究区。点亮第一座重构塔，获得钻头形态。
2. **齿轮工坊**：自动化工厂区，传送带与活塞，获得气泡形态。
3. **晶簇深渊**：星球的矿层，发光水晶与漆黑洞穴。
4. **云顶之城**：殖民首都，空中轨道与玻璃穹顶。
5. **锈海**：锈蚀最严重的区域，方块在不断腐坏、塌陷。
6. **终章 · 星核**：方舟引擎所在的星球中心。

## 核心谜团（逐步揭示）
- 为什么重构没有启动？（日志 → 艾拉发现日冕潮会在十年后再来一次，她犹豫了）
- 艾拉去了哪里？（她没有进入种子方块）
- NOVA 为什么对艾拉的事这么清楚？
  - 真相：NOVA 就是艾拉。她把自己的意识上传进引擎，守着这颗星球，也因为害怕再次失去一切，亲手冻结了重构。
  - PIX 一路点亮重构塔，也是在帮艾拉重新相信“拼回来”这件事。

## 结局
在星核，PIX 把最后一块核心方块放回原位。星球重构了：森林、湖泊、城市回来了，居民醒了过来。
但所有东西都还保留着一点方块的样子。NOVA（艾拉）说：“……算了，方块也挺可爱的。”
方舟引擎留在星核里继续运转：下一次日冕潮来的时候，他们知道该怎么做了。

## 基调
- 外表可爱、轻松，内核认真：牺牲、等待、信任、重建。
- 没有真正的“坏人”，锈块兽是生了病的机器，击破后会变回金币和能源。
- 文案短、克制，留白，不说教。
